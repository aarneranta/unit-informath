euclid

The original text
Lemma 8.10, p. 7
Statement. If $\gcdd(a,b)\mid1$ and $a\mid bc$ then $a\mid c$.
Proof. $a\mid ca$ and $a\mid cb$ ($cb = bc$), so $a\mid c\gcdd(a,b)$ by Lemma 8.9 with $u=c$. And $c\gcdd(a,b) \mid c\cdot1$$= c$ (div-scale). So $a\mid c$.
